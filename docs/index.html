The price of a world model

ARC-AGI-3 was solved on its public set this year for about $119 a game. Nobody has measured what happens when you spend less. This is the substrate to find out, the runtime at the free end of the curve, and the first results — including the ones that went against us.

How much of an agent can you own at $0? Two percent, today.

The delegation architecture says a frontier model should propose goals and read anomalies while a world model that costs nothing handles the steps it has already learned. Nobody had measured how many steps the free end could take. So we did, on games the learners had never seen, scored after the fact against what happened.

An action is delegable when the model committed to a prediction and the whole frame was right. The learners over-commit: synthesis claims 59% of actions and is right on under one percent of them. Gating on per-rule evidence changes nothing. Gating on completeness, committing only when the current theory reproduces the action's last frames exactly, lifts every learner to 20 to 50% right at about one percent coverage. The commit criterion is solved and cheap. The theories are what is incomplete. That is the research.

9 Sep 2026, morning

First measurement. Delegable 0.4% (synthesis), 2.0% (last-effect). Commit precision 0.7% and 8.6%.

9 Sep 2026, afternoon

Per-rule evidence gates: no change. Whole-effect gate: precision 8.6% → 51.4%, coverage 1.1%.

9 Sep 2026, evening

General completeness gate on every learner: 20 to 50% right, about 1% coverage. Requiring three repeats zeroes the synthesiser.

10 Sep 2026

A model in the loop, the way EvoSkill does it, on the same games with an open 8B model: 107 programs written, none survived the verifier, 0 commits, F1 0.000, 156k tokens. The $0 heuristic scores 0.181 on the same slice. The loop's value is in the model, and the model is what costs $119 a game.

What we got wrong, in the order we found out

A funder is not buying a result. They are buying what a person does when the evidence goes against them. Here is the record, because it is the strongest thing on this page.

7 September 2026 · a reviewer would have found this in five minutes

“Precision 100%, recall 78%, F1 0.875 on real messages.”

True, and beside the point: naive Bayes gets 0.965 on the identical split in a thirtieth of the time. Published in the README above our own number. The honest claim became readability costs nine points of F1, which nobody had priced before.

7 September 2026 · the novelty check our own document kept deferring

“Nobody has beaten this benchmark.”

False since July. Tycho hit 100.00 RHAE. The proposal was re-scoped in public from a better learner to the price of a world model, and the retraction has its own file.

7 September 2026 · our own benchmark, the week it was built

“The template learner reaches F1 0.253 held out.”

Adding a one-line baseline — replay whatever this action did last time — showed it beats the template learner outright on development data. Nobody made us run that comparison. The registry did, the moment it existed.

8 September 2026 · the central claim, tried twice in one night

“Programs that survive replay become primitives, and the library transfers.”

A library of concrete programs halved performance (0.204 → 0.105): colour literals carry confident wrong vocabulary between games. Making programs abstract made them transferable and too general to be selective (→ 0.087). Both reverted, both published. Abstraction is necessary for transfer and insufficient for selectivity. That is what the funded work is for.

9 September 2026 · the delegation number

“The free end of the curve can carry an agent's routine steps.”

Two percent of them, today, and only with a completeness gate does any learner get its commits right more than half the time. Published the day it was measured.

Run all of it

No API key, no GPU, no dependencies beyond the Python standard library. Every number on this page regenerates from one of these, and GitHub Actions regenerates the held-out table on every push.

git clone https://github.com/let-the-dreamers-rise/nyaya && cd nyaya
# the results table above, on data the learners never saw
python -m bench.run --corpus bench/corpus-heldout
# the delegation table, with the completeness gates
python scripts/delegation.py --corpus bench/corpus-heldout --complete
# learn a readable scam filter from 5,574 real messages, then open skill.py
python -m nyaya learn data/sms.tsv -o skill.py
# use it from any agent: three tools, stdlib only, nothing uploaded
claude mcp add nyaya -- python -m nyaya.mcp_server

Who is asking

A student in India, working solo. No lab, no cofounder, no credential worth listing — so the argument is the artefact. The runtime, the substrate, the engine, 249 tests, and five retractions of our own claims, all in ten days of a public repository. The reason nobody has measured the cost of these systems is that everyone positioned to is a funded lab with API credits. If your compute is free at the margin, price is not a variable you notice. Mine was never free, so the runtime was instrumented for tokens and milliseconds before I knew that was the interesting part.
